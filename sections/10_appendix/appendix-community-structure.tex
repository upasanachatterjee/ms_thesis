\chapter{Community Structure}
\label{appendix:community-structure}

Table~\ref{tab:community-structure} presents the community structure obtained from Louvain community detection on the topic tag co-occurrence graph described in Section~\ref{sec:experimental-design}. We show the top topics by popularity for each community. Each community groups semantically related topic tags that frequently co-occur within articles; the Theme column provides a descriptive label summarizing the dominant content of each cluster. The 14 detected communities range from single-topic clusters (e.g., Community~7: Defense) to large thematic groupings containing over 200 tags (e.g., Community~1: Elections and Campaigns, Community~8: International Affairs and Defense).
